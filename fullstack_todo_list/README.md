# Fullstack Todo List - Interview Assignment

Welcome! This is a **1-day take-home assignment** for building a complete fullstack Todo List application using modern tools and AWS.

## 🎯 What You're Building

A fullstack application with:

- **Frontend**: React + TypeScript + Tailwind CSS
- **Backend**: Express.js + TypeScript + DynamoDB
- **Infrastructure**: AWS deployment with Terragrunt (Lambda, API Gateway, S3, DynamoDB)

**Time**: 6-8 hours for core functionality (Phases 1-4). Phase 5 (testing) is optional.

## ✅ Quick Checklist Before Starting

Ensure you have:

- [ ] Node.js 18+
- [ ] npm 9+
- [ ] AWS account (configured with `aws configure`)
- [ ] Git installed
- [ ] Terraform 1.5+
- [ ] Terragrunt 0.50+
- [ ] Docker installed
- [ ] Text editor/IDE (VSCode recommended)
- [ ] Agentic tool available (free: Google Antigravity, Gemini CLI; paid: Claude Code)

Verify with:

```bash
node --version
npm --version
git --version
aws --version
terraform --version
terragrunt --version
docker --version
```
